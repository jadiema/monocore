# Module « ui480 » : l'interface des éditeurs en 640 × 480

`ui480` est la boîte à outils d'interface de **MONOPIXEL**, tirée de celle de MONOTRACKER. Elle
doit servir aux éditeurs à venir, comme le BASIC ou un éditeur de niveaux. L'écran est en
640 × 480 entrelacé (matériel version 5) et fait 80 × 30 caractères de 8 × 16, avec la police de
MONOTRACKER (`sdk/font480.h`, copie de `examples/monotracker/font480.h`). On y trouve des panneaux
gris en relief à la manière des programmes Amiga, un pointeur de souris, des zones cliquables, des
boutons, des compteurs ▲▼ et le clavier AZERTY ou QWERTY avec répétition.

Dans `project.txt` : `library = mc`, `modules = ui480` (avec d'autres modules si besoin :
`modules = mgfx ui480`).

## Ce que le module prend

| Ressource | Usage |
|---|---|
| plans 0 et 1 | le texte, lignes 0–14 et 15–29 : une carte de tuiles 8 × 8 ne couvre que 256 lignes, et le défilement par ligne cache dans chaque plan la moitié qui n'est pas la sienne |
| plan 2 | les panneaux, en tuiles 16 × 16 décalées de 8 pixels vers le haut : un panneau laisse une demi-ligne au-dessus et au-dessous de son texte |
| plan 3 | **libre** pour le programme, derrière tout le reste (priorité 0) : dessin, carte… |
| palettes 0–31 | couleurs du texte (0–7 sur fond sombre, 8–13 sur les panneaux gris), des panneaux, du pointeur ; le programme a les palettes 32–255 |
| sprite 0 | le pointeur ; `SPR_CHR` pointe sur le début de la CHR RAM (cellule = décalage / 32) |
| CHR RAM | 24 Ko (`UI_CHR_SIZE`) à partir du décalage donné à `ui_init` |

Le texte a la priorité 3 et les panneaux la priorité 1. Un sprite de priorité 3 à 5 passe donc
au-dessus des panneaux et sous le texte. MONOPIXEL s'en sert pour son zoom de dessin, qui est un
sprite agrandi par le matériel, avec la grille par-dessus en texte.

## Une image du programme

    ui_init(0x1A000);                      // une fois ; ui_ok() vaut 0 sur un core sans 640 x 480
    for (;;) {
      mc_frame();
      ui_frame_begin();                    // efface l'écran en cours de dessin, nouvelle liste de zones
      int k;
      while ((k = ui_key()) >= 0) ...;     // touches enfoncées (avec répétition des flèches...)
      const ui_zone_t *z = ui_zone_at(mc_mouse_x(), mc_mouse_y());   // zones de l'image précédente
      ui_box(0, 1, 79, 1, UI_RAISED);
      ui_print(1, 1, "MON EDITEUR", UI_INK_BLUE);
      ui_button(20, 1, 10, "SAUVER", false, Z_BOUTON, 0);
      ui_frame_end();                      // envoie ce qui a changé, garde les zones, place le pointeur
    }

On redessine tout à chaque image. Seules les cases qui ont changé sont écrites dans les tilemaps.

## Fonctions

| Fonction | Rôle |
|---|---|
| `ui_box(x0, y0, x1, y1, style)` | un panneau autour des caractères x0..x1 (x0 pair, x1 impair), lignes y0..y1 ; styles `UI_RAISED`, `UI_SUNK` (fond sombre), `UI_PRESSED`, `UI_FRAME` (cadre ouvert : le plan 3 et les sprites se voient dedans), `UI_HOLE`, `UI_BACK` (fond opaque sans relief, pour cacher le plan 3) |
| `ui_print`, `ui_printn`, `ui_printc`, `ui_printf`, `ui_put` | texte (majuscules sans accents : la police va de 32 à 127), glyphe seul |
| `ui_frame(x0, y0, x1, y1, pal)` | un rectangle de traits (couleur 1 de la palette) : sélections, survols |
| `ui_zone(x0, y0, x1, y1, id, arg)`, `ui_zone_at(px, py)` | zones cliquables, en caractères |
| `ui_button(x, y, l, texte, enfoncé, id, arg)` | un bouton d'une ligne, avec sa zone |
| `ui_spin(x, y, nom, ln, valeur, lv, id, arg)` | un compteur : zones `arg × 4` (▲), `+ 1` (▼), `+ 2` (la valeur) |
| `ui_glyph_define(g, lignes)`, `ui_glyph_tiles(g, haut, bas)` | glyphes du programme, de `UI_G_USER` (128) à 255 |
| `ui_key()`, `ui_char(touche)`, `ui_hex`, `ui_shift`, `ui_ctrl`, `ui_alt` | clavier ; `ui_layout` : 0 AZERTY, 1 QWERTY |
| `ui_message(texte)`, `ui_message_text()`, `ui_confirm(touche, quoi)` | ligne d'état, confirmation par un second appui |
| `ui_pointer_shape(0 ou 1)` | flèche ou croix de visée (dessin précis) |

Les glyphes du module sont `UI_G_SOLID` (un pavé de la couleur 3 de sa palette, pour les nuanciers),
les flèches, une coche, un point et les 16 traits de cadre `UI_G_FRAME + bits` (1 haut, 2 bas,
4 gauche, 8 droite).

Les traits horizontaux des panneaux et des glyphes font deux lignes d'épaisseur pour ne pas
scintiller en entrelacé.
